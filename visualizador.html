Inventário IFC

Conta as entidades de modelos IFC por disciplina e exporta as tabelas em CSV. Os arquivos são lidos só neste navegador; nada é enviado para a internet. Também abre o resultado.json gerado pela ferramenta em Python (inventario_ifc.py), que confere as contagens com o IfcOpenShell.

Abrir modelos IFC

Arraste os arquivos .ifc para a disciplina de cada um, ou clique na caixa para escolher. Também dá para abrir uma pasta que tenha uma subpasta por disciplina (Arquitetura, Interiores, Estruturas, Metálica). A contagem lê o texto do arquivo: o nome da entidade é o que está entre o primeiro = e o primeiro ( de cada linha que começa com #.
